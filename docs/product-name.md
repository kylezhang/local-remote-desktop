# Product name

[简体中文](zh-CN/product-name.md) · [Project layout and compatibility](naming.md)

The project owner confirmed **Local Remote Desktop** on 2026-10-10.
The AtomGit repository is now
[local-remote-desktop](https://atomgit.com/zkxw2008/local-remote-desktop).
This is the same private repository with its existing history, tags and releases.

The name describes remote desktop access on a local network, including future
phone/tablet controllers for desktop computers. Current source uses
`LocalRemoteDesktop` for the Windows assembly/namespace and Swift executable/target.
Application titles use **Local Remote Desktop**. The Mac application bundle is
`Local Remote Desktop.app`; Windows builds produce `LocalRemoteDesktop.exe`.

Paired passwords, connection preferences and received files retain their existing
storage locations. Mac bundle ID, Keychain service/account and LaunchAgent label
remain stable. Discovery service and credential/protocol markers remain compatible.
Installation still follows the existing signature and permission rules; renaming
cannot guarantee authorization survives an ad-hoc code update.

Previously published LocalRemote versions, tags, release titles and filenames
remain historical releases. The current development version is 0.3.0-alpha.1;
renaming does not publish a new release or claim Mac controller acceptance.
English remains the primary documentation language, with Chinese equivalents.
