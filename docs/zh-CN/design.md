# 界面设计

[English](../design.md) · [产品方向](product.md)

**2026-10-12 已确认。** [先选用途方案](entry-design.md)替代第二轮设计，成为当前桌面实现依据。
打开[交互设计](../../design/entry-review/index.html)或[三页总览](../../design/entry-review/overview-zh.png)。

首页只保留大标题和两个同等明显的入口：**发起连接 / 接受连接**。没有副标题、常驻侧栏
或凭据表单。配套双屏插图用蓝色标出被操作屏幕，属于任务插图，不是重复的应用 logo。

选择入口只进入对应页面，不自动连接、授权、改密码或停止监听。“返回”回到首页；正在
接受连接时仍有“查看或停止”的明确入口。设置统一放在右上角，并保留文字标签。
远程画面继续使用紧凑工具栏，断开后回到连接任务，不强制再次选用途。

发起连接页只有一个设备列表和一个“添加目标”入口，地址和密码按需弹出。设备名称、系统
来自发现信息、已认证目标或保存记录；未知 IP 不臆造名称。发现不等于授权，认证成功后才
安全保存密码，失败和取消保留原有保护。

接受连接页将本机名称、系统提供的 IP、隐藏密码竖向组织，开始/停止接受连接固定在底部。
名称或密码有未保存草稿时不能开始，但已经运行的停止动作仍可用。自动生成只填写 8 位
草稿，取消不改密码；成功保存结束旧会话，等待主动开始。旧长密码在主动修改前保留。
Mac 权限恢复属于此页；选择用途本身不请求权限。

默认外框约 600×680 逻辑单位，保留各平台原生字体和窗口控件。统一留白、白色内容、
中性表面及 #5265EC 强调色；长内容滚动，停止动作可达。Windows、Mac 使用同一套已确认插图。

设置仍分通用、连接、剪贴板、关于。默认选项只影响新连接，会话选项不能扩大本机允许的
剪贴板/文件权限。现有加密协议和凭据身份保留。

预览数据和交互均为模拟，不代表原生运行验收。构建和检查证据见[原生进度](native-ui.md)。
[第二轮设计](../../design/review/README.md)保留为历史记录；未来手机/Linux 草图不表示已支持。
