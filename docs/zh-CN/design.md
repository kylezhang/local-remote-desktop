## 日常使用流程

**打开 → 选择设备 → 连接 → 工作。** 一个应用提供“连接”和“共享此设备”两个角色。
桌面导航将这两个任务放在上方，设置放在底部，远程操作时收起。设备列表和右侧详情
集中在连接任务上，不做卡片仪表盘。不常驻局域网口号，不重复 logo，不在远程画面
上保留地址密码输入栏。

在线且已记住的设备，一次点击使用已保存的密码连接。首次连接在详情里输入密码，
错误后保留内容方便修改。手动目标IP与密码合并为一个对话框。已记住但离线的设备
仍可辨识，不显示“可连接”。发现设备不等于授权。“忘记密码”仅移除所选目标的
保存凭据，不重置全部偏好，也不清除本机共享密钥。

设备名称和系统来自设备广播或保存的记录，不能从 IP 推断。手动输入 IP 时，
若存在匹配记录，就在弹窗中显示；否则先显示地址，连接成功后再用已认证目标返回的
信息更新列表和会话名称，不产生重复条目。认证后的设备名称仍需补入实际协议，
当前离线原型仅模拟这个流程；配对失败或取消不添加设备。

共享页管理本机名称、IP、隐藏的密码、等待/使用状态以及明确的停止按钮。
切换页面不停止共享。修改密码打开草稿：自动生成只填写草稿，取消不改变密码，
保存前明确说明会停止共享、断开当前连接。屏幕或输入权限的恢复入口放在共享页，
连接另一台设备时不申请这些本机权限。缺少输入权限时标明只能查看。

新设密码统一为 8 位且不含空格，手动填写和自动生成遵循同一规则。“自动生成”
使用明确的描边按钮。原生客户端已有密码在主动修改前继续有效，更新不能截短密码。

“共享此设备 → 本机名称 → 修改名称”编辑本应用对外展示的名称，默认读取系统名称。
“使用系统名称”只填写草稿，取消保留原值，保存后更新名称而不停止共享或修改密码。
自动发现和已认证连接使用同一名称，系统类型由目标应用自动报告。改名不改变操作
系统中的电脑名称，不新增重复设备，也不清除保存的配对凭据。原生名称编辑入口和
认证后名称字段仍待实现。

当前单一角色的限制使用明确的“停止共享并连接”处理，先检查目标信息，再由用户
明确执行；取消保留现有共享，选中设备不会自动停掉共享。未来并行角色需要单独
实现与验收。

## 设置分类与作用范围

| 分类 | 内容 |
|---|---|
| 通用 | 语言、拟定的主题选择 |
| 连接 | 新连接的画质、重连、快捷键默认选项 |
| 剪贴板 | 文字/文件共享的本机全局许可，接收目录 |
| 关于 | 版本、GPL 许可，可展开的问题排查 |

系统权限和本机共享密码留在共享页，目标密码在连接页管理。诊断为次要操作，不让
开发计数器占据日常界面。

远程工具栏管理画质、全屏、本次会话选项和断开。本次会话可以临时限制文字/文件
同步或调整快捷键，但不能绕过关闭的全局剪贴板许可。关闭全局共享后立即停止相应
同步，需要两端均允许。“以后连接的默认设置”与“当前逻辑会话的调整”分开，
切换画质和临时重连也要保持这个作用范围。

重连时最后画面变暗并标注暂停，取消结束重试并断开。文件传输显示临时进度和取消
操作；取消传输不影响桌面连接。

## 可落实到原生客户端的视觉

保留已确认的蓝莓图标和主色 #5265EC。正文使用中性深色 #202435、辅助色 #697183，
白色内容区、#F6F7FA 导航底色与 #E5E8F0 分隔线。渐变留在图标里。使用一致的
线形图标、克制的选中底色和原生窗口标题栏，不用不相关的字符代替图标。

Windows 使用 Segoe UI Variable/Segoe UI，Apple 使用系统字体。正文 14px，辅助
12px，标题 25px；间距按 4/8px 递进。内容区留 32–36px 边距，设置控件保持稳定
对齐，不一路拉到窗口最右边。约 174px 导航栏和 42px 会话工具栏，为实际工作留
空间。控件、选中标记、对话框采用有层次的圆角。窄窗口将列表与详情上下排列，
避免挤压表单；保留可见焦点、翻译空间、减少动画、系统缩放和原生深色效果。

手机使用相同的连接/共享/设置词汇和底部导航，进入会话后切换触控板/直接触控、
键盘和选项操作栏，点击区域至少 44px。手机共享方案当前仅查看，每次需系统确认，
不承诺完整无人值守控制，见[移动端可行性](mobile-sharing.md)。

## 审阅后再实现

主题选择、Mac 控制端记住密码、反向发现/剪贴板/文件，以及诊断脱敏仍需实现和
验证。原型中能点击不代表平台能力已经完成。

确认后提取共用视觉参数、文案和状态，逐步落实到 Windows 和 Mac 原生界面，按
尺寸、语言、缩放比较实际截图。本次布局改动不改变 bundle 身份、钥匙串、签名
或系统授权。Windows 主程序统一为 `LocalRemoteDesktop.exe`，去掉本地部署的
`LocalRemote.exe` 兼容改名，更新快捷方式，保留用户偏好，不再复制多份 exe。
部署时不打断正在使用的会话。

原生构建以及两端配对、输入、剪贴板、文件与重连实测仍是发版条件。浏览器审阅
不能替代这些检查，本轮设计修改不代表已打 tag 或发 release。
