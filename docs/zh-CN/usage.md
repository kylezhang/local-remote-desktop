# 使用指南

[English](../usage.md) · [README](../../README.zh-CN.md)

## 连接与控制

Mac 保持唤醒、正常登录，开始共享。在 Windows 填入 Mac IPv4、64 位十六进制配对密钥，选流畅后连接。首次默认 IP 可能是 Windows 本机局域网地址，仅方便修改同网段，并非自动发现；有记忆时优先恢复上次 Mac 的地址与密钥。

点击画面获得键盘焦点。开发更新默认勾选“Windows 快捷键”：Ctrl→Command、Win→Control、Alt→Option、Shift→Shift，Ctrl+C/V/X/A/Z/S 对应 Mac 的 Command 快捷键；Ctrl+Shift 组合保留 Shift。切换模式会释放远端已按下的键，并记住选择。取消勾选后恢复原映射 Ctrl→Control、Win→Command，可用于终端 Control+C 中断。已发布 v0.1.0 安装包仍使用原映射。

上述快捷键操作 Mac 自己的剪贴板，跨设备传递文本需另行开启下方功能。Alt+Tab、Win 组合等 Windows 保留键可能留在本地；Windows 输入法组合文本不传输，可用 Mac 本身输入法处理物理按键。

F11 全屏，Ctrl+Alt+Esc 释放输入并回到本地焦点。点击本地按钮也会移走键盘焦点。Mac 停止共享或退出应用即可结束共享；只关闭窗口不会退出后台应用。

## 文本剪贴板同步（开发更新）

两端更新主分支：Mac 勾选“允许双向文本剪贴板同步”，Windows 勾选“同步文本剪贴板”。
等 Windows 显示“已启用”后重新复制。应用每次启动默认关闭，切档/重连保留本次选择。
旧 Mac 不支持时仅显示不支持同步，远控仍可继续；只开启 Windows 时等待 Mac 允许。

- Windows 本地复制文字，点击远端画面，再 Ctrl+V（启用 Windows 快捷键）。新文本会先于粘贴按键进入同一加密连接。
- Mac 远端用 Ctrl+C，或在 Mac 本地用 Command+C。等待约半秒加网络延迟，再到 Windows 本地应用粘贴。
- 任一端关闭或断开即停止同步及待重试写入。已经收到的文字保留在系统剪贴板，传输中的数据不能撤回。

仅同步新复制的纯文本，保留中文、emoji、换行；上限 **32 KiB UTF-8**，不是固定字数。
超长或含 NUL 的文本跳过，不截断；不传图片、文件、富文本格式。收到文本会替换原剪贴板格式。
开启和重连时不发送已有内容，所以等“已启用”后重新复制。开启期间复制的密码等敏感文字也会发送，只对可信配对设备使用。

每 500 毫秒检查变化，收到的内容不回传；剪贴板忙时最多重试两秒，新本地复制取消待重试写入。
两端同时复制可能竞争，不提供剪贴板历史；远端刚复制或系统剪贴板占用时不要立即粘贴。
LocalRemote 不记录或保存文本内容。Windows 界面/加密连接及 Swift 状态/适配模拟测试通过，
Mac 原生 AppKit、安全框及真实两机粘贴仍待验收，见[验证状态](validation.md)。

## 画面质量

| 档位 | 请求上限 | 请求码率 |
|---|---|---|
| 流畅 | 1280×720，30fps | 4Mbps |
| 标准 | 1920×1080，60fps | 10Mbps |
| 高清 | 1920×1080，60fps | 18Mbps |

这是请求值，不是实测性能保证；操作卡顿先选流畅。Windows 目前软件解码。连接中切档会释放输入、关闭旧流，约三秒后自动重连；连续选择采用最后一档，关闭自动重连也能切档。普通网络恢复重连则需要之前认证成功且启用自动重连。

## 连接与权限帮助

- 允许 TCP 47980 到 Mac，文件共享还需 47981；访客 Wi-Fi 隔离或 VPN 路由可能阻断互通。
- Mac 授权屏幕录制及辅助功能，授权后退出重开，不要为重开再次安装。无辅助功能时可能只能看、不能控制，详见 [Mac 排障](macos.md)。
- 密钥保存在 Mac Keychain 与 Windows 当前用户 DPAPI。“忘记连接”清除所选 Windows 连接。不要在问题反馈、截图或公开消息中带上密钥。
- 复制诊断不包含密钥和输入内容；点击诊断按钮后 KeyboardFocus=false 正常，HostPosted 是 CGEvent 提交数量，不是目标应用确认接受。

## 会话支持

单控制端、主显示器、IPv4。已发布 v0.1.0 无剪贴板同步，开发构建文本同步见上文。
开发构建另有可选普通文件复制粘贴，见[文件指南](files.md)。尚无音频、录屏和发现。Mac 须唤醒登录，不绕过 FileVault 预启动、不创建新登录会话、不保证锁屏或安全框输入。

协议有认证加密，但未独立审计、无前向保密。仅可信局域网，不公开端口。详见 [协议](protocol.md)及 [构建测试状态](validation.md)。
