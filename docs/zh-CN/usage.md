# 使用指南

[English](../usage.md) · [README](../../README.zh-CN.md)

## 界面组织

主分支开发版两端均可在“设置 → 语言”中选择 English 或简体中文。首次跟随系统语言，
主动选择后记忆，切换不影响当前连接、密码或剪贴板选择。已发布 v0.2.0-beta.1 仍为中文界面。

开发版桌面端在同一窗口提供“连接”“共享此设备”和“设置”。连接期间收起导航和凭据，
用紧凑会话栏管理画质、全屏、选项及断开；性能和文件详情按需显示。共享页默认隐藏密码，
提供明确的编辑与取消流程；查看/复制密码不启动共享。已确认的第二轮设计正逐步接入，
待实现及验证范围见[原生界面进度](native-ui.md)。

设置分为“通用、连接、剪贴板、关于”。连接选项是未来连接的默认值，远程工具栏的
画质、重连及快捷键选择只作用于当前会话。剪贴板设置是本机总允许状态，会话选项只能
进一步限制，不能开启已全局关闭的类别。连接页“忘记密码”只删除所选目标保存的密码，
保留地址和本机共享密钥；Mac 权限恢复入口位于共享页。

## 本机名称（开发更新）

在“共享此设备”的“本机名称”旁点击“修改名称”。默认读取系统名称，可保存 1–32 个
Unicode 字符的应用展示名称。取消保留原值，“使用系统名称”只填写草稿，保存才生效。
保存不修改操作系统中的电脑名、不更换密码，也不结束共享。

Mac 共享期间向局域网发布这个名称；已配对目标也通过现有连接返回名称和系统，改名
后心跳更新会话标题。新手填 IP 在目标返回信息前没有名称/系统；旧目标保留已知名称或 IP。
Windows 刷新时保留当前进程内已连接记录，持久设备历史及反向发现仍待实现。

## 连接与控制

Mac 保持唤醒、正常登录，开始共享。Windows 选择附近设备，或填写 Mac IPv4 和配对密码，
选流畅后连接；旧的 64 位密钥仍受支持。首次默认 IP 可能是 Windows 本机局域网地址，仅
方便修改同网段；有记忆时优先恢复上次目标。选择发现的设备只填写地址，不自动连接。

点击画面获得键盘焦点。开发更新默认勾选“Windows 快捷键”：Ctrl→Command、Win→Control、Alt→Option、Shift→Shift，Ctrl+C/V/X/A/Z/S 对应 Mac 的 Command 快捷键；Ctrl+Shift 组合保留 Shift。切换模式会释放远端已按下的键；工具栏的选择临时生效，未来默认值在“设置 → 连接”保存。取消勾选后恢复原映射 Ctrl→Control、Win→Command，可用于终端 Control+C 中断。已发布 v0.1.0 安装包仍使用原映射。

上述快捷键操作 Mac 自己的剪贴板，跨设备传递文本使用下方独立功能，当前开发版本默认开启。Alt+Tab、Win 组合等 Windows 保留键可能留在本地；Windows 输入法组合文本不传输，可用 Mac 本身输入法处理物理按键。

F11 全屏，Ctrl+Alt+Esc 释放输入并回到本地焦点。点击本地按钮也会移走键盘焦点。Mac 停止共享或退出应用即可结束共享；只关闭窗口不会退出后台应用。

## 配对密码（开发更新）

两端更新主分支。在 Mac“当前密码”旁点击“修改密码”，在独立编辑窗口手填新密码或点击“自动生成”，再点击“保存密码”。
“自动生成”仅填写编辑框，保存后才生效。手填支持 8–64 位英文字母、数字或符号，不含空格，区分大小写；
自动生成 12 位随机大写字母/数字，避开 0、1、I、O。建议生成随机密码，避免常用单词或纯数字 PIN。

保存会更新原有钥匙串记录并断开当前控制端；原来正在共享时会用新密码重新启动共享。
Windows 先断开以展开连接输入框，填同一个密码再连接；仍以 DPAPI 记住密码。
正常重启或安装不会主动更换密码。取消会清空未保存的草稿，不改变密码或共享；空值、非法值、相同密码不能保存。
保存失败在编辑窗口提示并保留草稿，原密码及共享会话保持；编辑后清除旧错误。保存中不能取消编辑；
停止/退出期间若保存完成，也不会重新启动共享。macOS 仍可能要求钥匙串授权。

原来的 64 位密钥不会自动变化，直到主动保存新密码。新 Windows 客户端兼容两种方式，
旧 Windows 客户端不能连接采用短密码的 Mac。已发布 v0.1.0 包仍使用旧密钥。
Mac 原生钥匙串更新及重启后的实际效果仍待验收。

## 文本剪贴板同步（开发更新）

两端更新主分支：文字同步默认开启，曾主动关闭则保留关闭状态。两端均在“设置 → 剪贴板 → 同步文字”调整。
等 Windows 菜单中显示“已启用”后重新复制。应用重启、切档及重连都会保留选择。
旧 Mac 不支持时仅显示不支持同步，远控仍可继续；只开启 Windows 时等待 Mac 允许。

- Windows 本地复制文字，点击远端画面，再 Ctrl+V（启用 Windows 快捷键）。新文本会先于粘贴按键进入同一加密连接。
- Mac 远端用 Ctrl+C，或在 Mac 本地用 Command+C。等待约半秒加网络延迟，再到 Windows 本地应用粘贴。
- 任一端关闭或断开即停止同步及待重试写入。已经收到的文字保留在系统剪贴板，传输中的数据不能撤回。

仅同步新复制的纯文本，保留中文、emoji、换行；上限 **32 KiB UTF-8**，不是固定字数。
超长或含 NUL 的文本跳过，不截断；不传图片、文件、富文本格式。收到文本会替换原剪贴板格式。
开启和重连时不发送已有内容，所以等“已启用”后重新复制。开启期间复制的密码等敏感文字也会发送，只对可信配对设备使用。

每 500 毫秒检查变化，收到的内容不回传；剪贴板忙时最多重试两秒，新本地复制取消待重试写入。
两端同时复制可能竞争，不提供剪贴板历史；远端刚复制或系统剪贴板占用时不要立即粘贴。
Local Remote Desktop 不记录或保存文本内容。Windows 界面/加密连接及 Swift 状态/适配模拟测试通过，
Mac 原生 AppKit、安全框及真实两机粘贴仍待验收，见[验证状态](validation.md)。

## 画面质量

| 档位 | 请求上限 | 请求码率 |
|---|---|---|
| 流畅 | 1280×720，30fps | 4Mbps |
| 标准 | 1920×1080，60fps | 10Mbps |
| 高清 | 1920×1080，60fps | 18Mbps |

这是请求值，不是实测性能保证；操作卡顿先选流畅。Windows 目前软件解码。连接中切档会释放输入、关闭旧流，约三秒后自动重连；连续选择采用最后一档，关闭自动重连也能切档。普通网络恢复重连则需要之前认证成功且启用自动重连。

## 连接与权限帮助

- 允许 TCP 47980 到 Mac，文件共享还需 47981；访客 Wi-Fi 隔离或 VPN 路由可能阻断互通。
- Mac 授权屏幕录制及辅助功能，授权后退出重开，不要为重开再次安装。无辅助功能时可能只能看、不能控制，详见 [Mac 排障](macos.md)。
- 密钥保存在 Mac Keychain 与 Windows 当前用户 DPAPI。“忘记连接”清除所选 Windows 连接。不要在问题反馈、截图或公开消息中带上密钥。
- 复制诊断不包含密钥和输入内容；点击诊断按钮后 KeyboardFocus=false 正常，HostPosted 是 CGEvent 提交数量，不是目标应用确认接受。

## 会话支持

单控制端、主显示器、IPv4。已发布 v0.1.0 无剪贴板同步，开发构建文本同步见上文。
开发构建另有可选普通文件复制粘贴，见[文件指南](files.md)。尚无音频、录屏和发现。Mac 须唤醒登录，不绕过 FileVault 预启动、不创建新登录会话、不保证锁屏或安全框输入。

协议有认证加密，但未独立审计、无前向保密。仅可信局域网，不公开端口。详见 [协议](protocol.md)及 [构建测试状态](validation.md)。
