# v0.1.0 验证范围

[English](../validation.md)

环境：Windows x64，.NET SDK 8.0.425，桌面/Core 运行时 8.0.31，2026-10-08。最终构建的原始结果位于 tests/results/。

2026-10-09 命名迁移：LocalRemote Windows 工程/程序集实际构建并打独立包，最终包内 DLL 通过 WPF 模拟端回归。
协议测试验证 DPAPI 原密文迁移、可解密、不覆盖新设置、保留原文件、忘记后不复活。Mac 旧应用位置、回退、自启动路径及忽略的签名配置迁移通过模拟。
共享 Swift 启动检查仍以 Linux 真实编译器执行；Apple SDK 和原生安装仍待验收。历史结果记录保留当时源码和产物名称。

2026-10-09 MacPackageChecks：便携检查覆盖缺失图标、错误版本/架构、开发模式、多余文件、图标格式、危险 ZIP 条目、内容篡改及来源不符；
模拟发布覆盖无效身份、未提交/版本不符、缺少 runtime/时间戳、调试权限、公证拒绝/失败、票据附加和解压后校验失败、源码变化、不覆盖已有输出。
成功路径验证附加票据后重新打包及校验值。未执行真实 Apple 签名、公证、Gatekeeper。
签名模拟另验证全新构建包，以及移动失败或终止时恢复旧构建产物，不操作已安装的应用。

最新开发更新：MacStartupChecks 在 Ubuntu 22.04 使用 Swift 5.9.2 编译执行产品的 SharingPreparation。
七个场景覆盖权限失败零密钥读取、顺序/缓存/重检、独立读取复用、失败不自动重试及三个取消边界。
Mac 上同脚本还会编译完整 Apple SDK 工程，此平台检查尚未运行。

Windows 新增快捷键模式测试：真实 WPF 的 Ctrl+C/V/X/A/Z/Y/S/F 组合以 Command 按键和标志经加密模拟端接收，验证释放顺序、模式切换、原生 Control+Shift、本地释放键。
协议测试覆盖全部修饰组合和隔离路径中的 DPAPI 设置保存、缺失/损坏恢复；不证明真实 Mac 应用接受，也不代表跨设备剪贴板同步。

未发布的 v0.1.1 工作（2026-10-09）：安装测试增加后期移动/验签/元数据失败、中断回退、恢复备份保留、首次安装清理和启动失败。保留权限检查覆盖临时签名改变、重复副本不兼容、要求无法读取、验签失败时不停止旧程序、不重置权限。钥匙串启动策略及静默读取仅通过语法检查，未原生编译或运行。见[发布检查清单](next-release.md)。
协议测试覆盖认证、TCP 分片、错密钥/篡改/重放/超长拒绝、真实 H.264 解码、合成密钥 DPAPI、输入队列及坐标边界。客户端测试使用真实 WPF 窗口与 FFmpeg，连接加密模拟 Host，覆盖画面、字母/顶排/数字键盘/修饰键、鼠标拖动滚轮、失焦释放、权限状态、断开与画质重连；快速切档及关闭自动重连也测试。测试窗口不激活、不读写真实连接凭据。

Mac 安装/签名脚本以临时目录和模拟工具验证替换、重复进程、启动代理、失败保留、显式定向权限重置、固定身份及失效拒绝临时签名。没有实际 TCC、launchd 或证书操作。完整 Apple 框架源码只做语法检查，共享启动逻辑另有实际 Swift 编译执行；plist、图标、文档链接及包内容检查不等于 Apple SDK 编译。

用户反馈真实 Windows→Mac 已满足大部分需求；这不是可重复实验室性能测量。本发版环境不能构建运行 Mac，最终品牌/图标更新未原生验证，不提供 Mac 二进制。锁屏/安全输入、权限、硬件编码、休眠唤醒、长时间会话及 1080p60 等仍需实机验收。

ReleaseChecks 另检查版本一致、兼容身份、图标文件、文档链接及基本已跟踪文件/敏感标记；不是完整安全审计。

保留的 decoder-latency-comparison.json 是历史合成解码缓冲比较，不是局域网端到端延迟。测试执行命令见英文对应页。后续 Mac 验收应验证普通输入、切档、断开本地继续、正常解锁登录后的自启动及稳定签名升级，不发布密钥和输入内容。
