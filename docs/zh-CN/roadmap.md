# 路线图

## 桌面优先级

有序工作维护在[交付计划](v0.3.0-plan.md)，每方向验收使用
[桌面清单](desktop-acceptance.md)。

1. **P0**：正确输入/释放，可预测的 Mac 授权、凭据及实际临时签名升级。
2. **P1**：双向文字/文件、取消/撤销、配对/发现、画质/恢复及测量的持续资源表现。
3. **P2**：最终包完整性和双语支持系统/安装/使用说明，与修复并行。

两端角色已实现，当前缺口是验收。完善 Mac → Windows 时保持 Windows → Mac 回归。
沿用原生 Swift/C# 和现有认证协议，不做大重写。
文件服务跟随接受会话，不固定于某系统，不默许建立互相控制。

交互测试暂停；继续后台审查、隔离检查和 GitHub Actions，
不打开应用或更改个人权限，后续用户参与集中在约定时段。

## 分发与发版规范

- 英文主文档、中文同步，按[界面规范](interface.md)统一
  **发起连接 / 接受连接**，采用原生字体和快捷键。
- 付费 Apple Developer 不是前提，临时签名/未公证包需准确的首次打开/升级说明和
  安装后实测；Developer ID/公证可选。
- 保留兼容身份和配对，不为无关改动重置权限；系统要求的授权仍可能发生。
- v0.x 新能力用次版本、兼容修复用补丁；v1.0 起补丁修缺陷、次版本加兼容功能、
  主版本承载不兼容变更，迁移须说明和验证。
- 对齐版本、更新日志、说明、tag 和文件名，Mac 内部构建号可独立递增。
  不移动 tag 或覆盖发行附件。
- 源码提交 AtomGit，现有镜像触发 GitHub Actions；云端核验后自动同步发行。
  主页最新不等于稳定认证，见[发版流程](../releasing.md)。

私有直连可用已有 VPN；发现可能依赖本地组播，手填 IP 是有效方式。
不做账号、公网穿透、云中转、新登录会话、FileVault 预启动或通用锁屏/登录/安全桌面控制。
先可靠地完成支持的桌面流程，再增加平台。
