# 路线图

[English](../roadmap.md) · [README](../../README.zh-CN.md)

目标是各平台安装同一个产品的对应版本，通过统一界面发起或接受局域网远程控制。接受连接必须授权，发现设备不代表信任。以下是方向，不承诺日期。

## v0.1.0：首次产品发布

整理当前 Windows→Apple Silicon Mac 同会话控制、配对加密、连接记忆、全屏、重连、连接中切画质及权限诊断。统一名称、图标和版本，提供双语文档、清理原生主线及发版产物。此前开发版本保留在 Git 历史，不改写历史。

## 下一阶段：日常使用稳定

优先补齐 Mac 原生构建和实机测试、稳定签名与打包、权限/钥匙串更新、键盘布局、断开释放、休眠唤醒及真实延迟测量。面向全球分发前增加英文界面及中文本地化，保持控件与英文文档一致。有数据支持时再替换 Windows 硬件解码与渲染。手填 IP 链路稳定后增加发现、显式配对与撤销；评估有大小限制、可关闭的文本剪贴板同步。完成标准：可重复的两机验证、明确升级行为，不依赖反复重置权限。

## 随后：Windows ↔ Mac

增加 Windows 桌面捕获及输入接收、Mac 查看和控制界面。在合适处复用已验证协议；每个平台提供“连接设备”和“允许连接”，内部仍区分权限。完成标准：真实硬件验证双向控制、授权、断开释放及本地继续工作。

## 后续：手机控制端及其他桌面平台

手机先作为已授权桌面的控制端，适配触摸、键盘和小屏导航。按测试条件评估 Linux。不能默认承诺 iOS/Android 支持无人值守被控，需分别评估平台限制。

## 边界

局域网优先，不做账号、公网穿透或中转、云中心服务、FileVault 绕过。当前不扩展文件传输、多显示器、音频、录屏、摄像头及组织管理。可靠性和安全优先于平台数量。
