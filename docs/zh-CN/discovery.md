# 附近设备

[English](../discovery.md)

开发源码只在“共享此设备”成功启动监听后发布设备。Windows 使用系统 DNS-SD，Mac 使用
Bonjour。Windows 可发现兼容的 Mac 和 Windows 共享服务；Mac 控制端目前只显示 Windows
目标，尚未实现 Mac 控制 Mac。选择列表条目不会自动连接或授予控制权限。

通过“连接 → 附近设备”选择，或点击“输入目标IP”。名称来自对方应用中的“本机名称”，
默认读取系统主机名；系统标签来自对方平台信息。单独填写 IP 不会识别名称与系统，
认证成功后才展示对方信息。展示名称不作为密码身份。

## 发布与搜索

两端使用 `_localremote._tcp.local`、TCP 47980，以及 TXT `protocol=1`、
`platform=macos|windows`、`deviceName`。不广播密码、账号或剪贴板。共享期间局域网可见
名称；改名重新发布而不停止监听或修改密码。停止共享或替换密码会撤销旧发布。
发现不可用时仍可手填 IP。

Windows 使用系统[异步 DNS-SD 注册接口](https://learn.microsoft.com/en-us/windows/win32/api/windns/nf-windns-dnsserviceregister)，
注册属于应用进程，退出后系统撤销。快速改名合并处理，同时只有一个原生操作。
停止/退出最多等待五秒 DNS 清理，桌面监听仍独立关闭；原生请求保留至回调完成，
不会提前释放。无常驻发现轮询，不需要额外安装 Bonjour。

Windows 打开时及主动刷新单次搜索三秒，最多四个 Ethernet/Wi-Fi IPv4 网卡、32 个结果，
DNS 追加请求有界；使用 [RFC 6762 临时端口查询](https://www.rfc-editor.org/rfc/rfc6762.html#section-5.1)，
不再占用 UDP 5353，也排除本机地址。Mac 使用五秒 Bonjour 搜索，最多解析 32 项，每项
解析超时三秒。刷新替换上一批任务，离开连接页或开始控制时停止浏览。不改防火墙或 DNS，
暂不支持 IPv6 发现。

## 最近设备与配对

认证后按地址保留唯一记录。Windows 在当前进程内保留信息；Mac 跨启动保留最多 32 条
不含密码的最近记录。列表明确区分“本次已发现”和“最近连接 · 本次未发现”，历史记录
不代表对方仍在共享。组播不可用时可刷新，或通过目标 IP 重试。

Mac 再次连接可在明确点击连接时读取钥匙串中的目标密码；启动、选择和刷新不读钥匙串。
手填密码只在认证成功后按记住选项保存，存储失败不断开连接；取消记住只跳过本次保存，
不删除旧密码。详见 [Mac 控制端](mac-controller.md)。Windows 原有 DPAPI 记忆继续保留。
发现信息、可修改名称和历史记录不能替代连接认证。

## 验证

Windows 使用临时测试信息实际通过系统 DNS 构造、注册回调、撤销和释放检查。
独立回环 UDP 覆盖两种平台、压缩/异常 DNS、过滤、请求上限及取消。发布操作替身检查
合并、延迟回调、失败不轮询；无窗口 WPF 检查选择、共享改名、主动发布和退出撤销。

Swift 生产发现/模型代码使用明确的浏览、会话和凭据替身编译检查，不等于原生 Bonjour、
钥匙串或 Apple SDK 验收。**新版 Mac 应用及真实双机组播/输入仍待完成。**
Mac 已不在同一局域网，SSH 尝试已停止。见[本轮记录](../../tests/results/discovery-pairing-2026-10-11.txt)。
