# 局域网设备发现

[English](../discovery.md)

开发构建在 Mac 成功开始共享后通过 Bonjour 发布设备。Windows 点击“目标IP”框内箭头选择。
选择只填写地址，并恢复该地址记住的密码；不会自动连接、配对或获得控制权限。
仅发现设备不会替换手填地址。手动填写 IPv4 始终可用。

打开 Windows 时搜索一次，或点击刷新搜索，单次三秒；不常驻轮询。
最多使用四个活动网卡、32 个结果，限制 DNS 记录及追加查询数量；当前仅显示兼容的 Mac 47980 服务。
设备名称和地址不代表身份可信，连接仍必须通过原有配对认证。

Mac 发布 `_localremote._tcp.local`，TXT 只含 `protocol=1`、`platform=macos`，不含密码、密钥、账号或剪贴板内容。
共享期间局域网可看到设备主机名；停止或更换密码时撤销旧发布，重新启动监听后再发布。

Windows 使用 [RFC 6762 单次查询](https://www.rfc-editor.org/rfc/rfc6762.html#section-5.1)，
从临时端口向 224.0.0.251:5353 发送查询并接收回复，不占用系统 5353 监听，不改 DNS/防火墙。
Mac 若提示局域网访问则按系统流程授权。网络隔离、组播过滤或防火墙可能影响发现，届时仍可手填 IP。
暂不支持 IPv6 发现。

Windows 已测 DNS 异常/压缩、端口/平台/地址过滤、分包、真实回环 UDP、取消和有界请求；
WPF 已测选择、手填兜底、窄窗口和发现不自动授权。实际 Swift 发布生命周期用 NetService 替身检查。
