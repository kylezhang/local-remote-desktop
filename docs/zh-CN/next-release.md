## 正式发布前必须完成

- [ ] 包含剪贴板开发实现的候选，须完成 Mac 原生剪贴板构建/运行及两机复制粘贴、允许/撤销、占用、Unicode/大小边界、重连及防回环验收。
  不以模拟替代原生结果；候选范围需与路线图版本对齐。

- [ ] 使用真实发布身份和公证配置执行 Mac 候选流程：签名、公证 Accepted、附加票据、最终 ZIP 解压验签和系统检查。
  流程及便携清单/来源校验已实现并模拟验证，尚未原生执行，见[维护者打包](macos-signing.md#维护者打包)。

- [ ] 使用真实 Apple SDK 编译更新后的 Host，包括已弃用的文件式钥匙串兼容接口。
- [ ] Mac 实机验证开发构建启动零凭据访问，证书构建可信/锁定/签名变化后的静默读取，拒绝/取消、
  重试和重启；配对密钥不变，无界面卡住、自动重试循环及诊断泄密。
- [ ] Mac 实机验证替换、保留权限更新、清理权限更新、图标、自启动和恢复。
- [ ] 有效固定签名身份及签名升级验证；说明临时签名限制，不提交签名凭据。
- [ ] 最终 Host 与 Windows 普通会话的查看/控制权限和重连回归；锁屏及
  FileVault 边界不变。
- [ ] 统一版本、标题和更新日志；构建验证最终 Windows 包、许可证及校验值；
  全部通过后在精确提交上打 tag 并创建 AtomGit Release。

2026-10-09 用户反馈保留权限更新后仍连续两次要求密码，多次重开，且必须
手动删除两项授权再添加才可共享。这是尚未通过的验收项。安装防护经过模拟，
共享启动逻辑已用真实 Swift 编译执行，但均不能证明原生钥匙串/TCC 行为。
见[签名与分发计划](macos-signing.md)，不将上述问题记为已解决。

当前 Windows 环境没有 Mac 原生构建和独立复现的钥匙串/TCC 验证。
不能宣称权限已永久修好或系统密码弹窗已消除。安装回退保护应用文件，
不能恢复之前的隐私授权、运行进程或硬断电状态。
