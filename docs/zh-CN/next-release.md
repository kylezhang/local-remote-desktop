# v0.1.1 发布检查清单

[English](../next-release.md) · [路线图](roadmap.md)

截至 2026-10-09：主分支开发中，**尚未发布**。公开应用版本暂保持 0.1.0，
准备发版时统一更新；Mac 内部构建号为 11。已有 v0.1.0 tag 和产物不变。

## 已实现及本地检查

- [x] 确认矢量品牌图形及各平台图标；Windows 构建、渲染通过。
- [x] 替换前校验新应用暂存签名和图标。
- [x] 完整替换，不混入旧资源；保留/重置权限选项均限定本应用。
- [x] 后期安装失败或中断/终止时回退旧包；恢复失败保留备份并说明位置。
  已在临时目录模拟验证。
- [x] 启动失败保留已验证的新包，输出处理指引。
- [x] 保留权限更新先比较签名要求并验证双方应用包，再停止旧程序或改变权限。
  不兼容、无法读取、验签失败时安全中止；模拟测试已覆盖。
- [x] 钥匙串读操作移到串行后台队列；临时签名及未标记构建等待用户点击，
  启动不访问凭据。证书构建在明确的原文件式后端使用旧式交互控制；
  显式认证/首次创建、本次运行复用密钥保留。仅语法检查，原生行为待验证。
- [x] 中英文说明、Git 整洁及发布基本检查。
- [x] 先检查屏幕再读密钥，保留独立查看入口；产品启动顺序、缓存、失败和取消逻辑已在 Ubuntu 用 Swift 5.9.2 实际编译执行，Apple 框架及弹窗待验收。
- [x] Windows 快捷键 Ctrl→Command、Win→Control，记忆选择、切换释放及原生模式。WPF 组合键经加密模拟端验证，真实 Mac 应用待验收，未增加跨设备剪贴板同步。

## 正式发布前必须完成

- [ ] 使用真实 Apple SDK 编译更新后的 Host，包括已弃用的文件式钥匙串兼容接口。
- [ ] Mac 实机验证开发构建启动零凭据访问，证书构建可信/锁定/签名变化后的静默读取，拒绝/取消、
  重试和重启；配对密钥不变，无界面卡住、自动重试循环及诊断泄密。
- [ ] Mac 实机验证替换、保留权限更新、清理权限更新、图标、自启动和恢复。
- [ ] 有效固定签名身份及签名升级验证；说明临时签名限制，不提交签名凭据。
- [ ] 最终 Host 与 Windows 普通会话的查看/控制权限和重连回归；锁屏及
  FileVault 边界不变。
- [ ] 统一版本、标题和更新日志；构建验证最终 Windows 包、许可证及校验值；
  全部通过后在精确提交上打 tag 并创建 AtomGit Release。

2026-10-09 用户反馈保留权限更新后仍连续两次要求密码，多次重开，且必须
手动删除两项授权再添加才可共享。这是尚未通过的验收项。安装防护经过模拟，
共享启动逻辑已用真实 Swift 编译执行，但均不能证明原生钥匙串/TCC 行为。
见[签名与分发计划](macos-signing.md)，不将上述问题记为已解决。

当前 Windows 环境没有 Mac 原生构建和独立复现的钥匙串/TCC 验证。
不能宣称权限已永久修好或系统密码弹窗已消除。安装回退保护应用文件，
不能恢复之前的隐私授权、运行进程或硬断电状态。
