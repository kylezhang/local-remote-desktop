# 桌面集中验收 — v0.3.0

[English](../desktop-acceptance.md) · [交付计划](v0.3.0-plan.md)

整理于 2026-10-11。这是 Windows ↔ Mac 的集中实机验收清单，不表示已完成。
自动检查使用隔离对端和记录服务；真实输入只在约定时段、专用目标上进行，使用无敏感内容的样例。

## 一次准备

维护者先从精确提交构建 Windows 包和当前 Apple SDK 下的 Mac 源码，记录提交、系统、
构建与签名并自行解决构建错误，再安排交互验收。按授权恢复 SSH 后，2026-10-13 的 Mac
原生 SDK、隔离应用包及不显示窗口的布局检查通过；安装后交互/权限与真实双机验收仍待完成。

使用可达私有网络（局域网或已有 VPN），目标先开启共享。TCP 47980 为桌面/控制，47981 为普通文件。
发现可能不跨 VPN；手填目标IP是有效测试路径。使用专门的配对密码与可删除文字/文件，
结果不提交真实密码、IP、剪贴板内容或工作画面。

## 两个方向各完成一次日常流程

| 检查 | 通过标准 |
|---|---|
| 首次/再次连接 | 名称与系统来自对端 App；错密码保留可编辑草稿；自愿记住后再次连接无需重复输入。 |
| 主界面 | 默认外框 600×680，受可用屏幕限制；任务选择首页；只有一个添加目标入口，点击设备打开连接表单，刷新不能自动弹出。区分空列表、附近和最近设备；接受连接信息与密码竖排，主操作在页底，设置按内容收拢。检查中英文与最小宽度。 |
| 当前桌面 | 真实画面更新；鼠标位置、点击/拖动/滚轮、字母/数字/数字键盘在目标应用生效；断开保留工作现场。 |
| 快捷键与退出 | 复制粘贴符合目标系统；丢焦点/断开释放按键与鼠标；本机释放/全屏不困住输入。仅事件提交计数不够。 |
| 文字剪贴板 | 启用后重新复制，Unicode 双向可粘贴；不回环、不覆盖更新的本地复制。 |
| 普通文件剪贴板 | 双向复制 Unicode 名、空文件、多文件；就绪后粘贴并核对字节/SHA-256。文件夹、虚拟文件、原始图片格式不在当前承诺中。 |
| 取消/撤销 | 中途取消或关闭同步，未完成批次清理，旧回调不发布；远控继续。重新开启后需新复制。 |
| 画质/重连 | 连接中切换各档，快速切换仅最后选择生效；短断网可恢复，断开取消等待；密码变更/认证失败停止重试并保留草稿。 |
| 角色生命周期 | 停止共享释放输入、监听与传输；再次启动可新配对；切页不另开 App 或默许反向控制。 |
| 唤醒/长会话 | 正常登录会话唤醒后可恢复；记录较长完整会话 CPU/内存/帧率/延迟及断开前后情况，无不断增长队列和孤立任务。 |

## Mac 安装与分发

1. 检查首次授权、屏幕录制/辅助功能拒绝与重试、显式钥匙串访问。拒绝时提示下一步，
   不自动重装、替换密码或反复认证。
2. 使用实际维护的签名身份连续升级两次。默认签名兼容检查通过后保留权限；
   不兼容时在停止/替换旧应用前中止。显式修复只重置本应用所选授权，系统仍需用户允许。
3. 核验配对持久化、有效权限、应用包/图标、自启动、完整替换与失败恢复。
   模拟安装不证明 TCC 生效，临时签名升级不算稳定产品升级路径。
4. 发布 Mac 二进制前核验 Developer ID、公证、票据和最终解压包；附精确源码、声明、来源与校验值。

不绕过 FileVault 预启动、系统登录/安全桌面，也不承诺任意锁屏控制；
这些边界与正常已登录会话的验收失败分开记录。

每项标记通过/失败/未运行，附方向、提交、系统/构建及去敏证据。
