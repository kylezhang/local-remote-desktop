## P0：先输入与 Mac 授权

同一候选分别验证 **Windows → Mac 和 Mac → Windows** 输入。

| 编号 | 通过标准 |
|---|---|
| I1 | 真实当前画面；实际 DPI/缩放、窗口缩放和全屏下位置正确，点击/拖动/滚轮命中专用应用，不误到任务栏。 |
| I2 | 字母、上排数字、数字键盘和目标系统复制粘贴在设置的映射下有效；系统保留组合键明确列为限制。 |
| I3 | 丢焦点、本机释放、断开和停止释放按键/鼠标；提交计数不能证明目标接受。 |
| M1 | macOS 14+ 主屏幕选择成功；取消/拒绝/重试有下一步，选择前不启动监听或反复访问钥匙串。macOS 13 使用全局屏幕录制权限。 |
| M2 | 辅助功能独立，拒绝时不宣称可控制；系统正常批准后真实输入到专用应用。 |
| M3 | 配对读/存/拒绝/重试/重开保留凭据和草稿，无未请求轮换或提示循环。 |
| M4 | 连续两次实际临时签名包升级有提示/恢复记录，保留配对和接受功能；本地脚本签名不兼容时替换前停止，下载包升级单独验证。 |

选择器仅授权采集。重开需重新选择，同次运行重连/画质复用源。
遵循[屏幕授权](mac-screen-access.md)，包含 macOS 14–15.1 单显示器限制。
一个云端 SDK/系统不能证明全部支持系统行为。

## P1：每方向日常流程

| 编号 | 通过标准 |
|---|---|
| D1 | 真实对端名称/系统，首次/记忆配对，错密码可编辑，主动记住；发现/刷新不授权或自动连接。 |
| U1 | 已确认任务首页，默认约 600×680 且适应屏幕，单一添加入口，空/附近/最近明确，接受内容竖排、操作在页底；双语、焦点、最小宽度和常规页容纳，保留用户调整大小。 |
| C1 | 新复制 Unicode 文字双向可粘贴，不回环、不覆盖较新本地复制。 |
| F1 | 新复制 Unicode 名、空/多文件就绪后双向可粘贴，字节/SHA-256 一致；文件夹/虚拟文件/原始图片不在当前范围。 |
| F2 | 取消/关闭清理未完成批次和旧回调，远控继续，重启同步需新复制。 |
| R1 | 连接中各档画质有效，快速切换仅最后选择；短断网恢复，断开取消重试，改密码/认证失败停止重试且草稿可编辑。 |
| L1 | 停止清理输入/监听/传输，再开始可新会话；切页保留角色/草稿，不另开应用或互相控制；断开保留目标工作。 |
| L2 | 正常登录会话唤醒/重连，安装图标、可选自启动、替换及所述失败恢复有效。 |
| R2 | 三档真实帧率/输入延迟基线，约定持续会话（初始至少 30 分钟），CPU/内存及重连/传输记录；无累积任务/队列或断开后继续工作。 |

写明硬件/方向/画质/方法，合成解码吞吐不等于局域网输入延迟。
首次持续测试是基线，不证明数小时均无泄漏。
