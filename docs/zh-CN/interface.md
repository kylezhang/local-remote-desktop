# 界面与交互规范

桌面初始外框约 600×680 逻辑单位（含原生窗口边框），在可用屏幕内居中并保留边距；
较小可用区域相应收缩。设置和表单按内容安排，不靠扩大窗口制造空白。
切换页面不重置用户调整后的窗口；长内容滚动，远程画面可调整大小/全屏。
手机按原生安全区和可用空间适配，不照搬桌面固定尺寸。
完整约定见[开发约定与经验](development-handbook.md)。

[English](../interface.md)

各端统一功能词汇、页面结构、操作流程和状态含义，保留系统原生控件、字体、权限弹窗及键盘习惯。
本规范用于 v0.2.0 界面完善与 v0.3.0 双角色开发；未实现的能力不显示成可用操作。

## 页面与操作

2026-10-17 屏幕连接台任务页批次将稀疏设置标签页改为四组连续列表。
连接页只有设备展陈和一个添加目标入口，主动点选后才打开配对；通用设备插画不是授权前的桌面缩略图。
接受连接页居中展示本机身份，IP 与密码竖排，开始/停止固定在底部。
权限、编辑器、默认值和全局允许状态边界保持不变。批次门槛见[原生实现清单](screen-desk-implementation.md)。

[已确认首页](entry-design.md)为“发起连接 / 接受连接”双入口，无常驻侧栏。
选择入口只导航，返回保留监听和草稿；设置统一在右上角带文字标签。

- **发起连接：**选择附近设备或填写“目标IP”，输入“配对密码”，然后连接。
  发现只填写地址，不自动配对或控制；保留连接记忆。
- **接受连接：**开始/停止共享当前桌面，管理密码；停止入口始终易于找到，共享需明确开启。
- **设置：**通用、连接、剪贴板、关于。连接默认值只用于新连接，当前会话选项临时生效。
  剪贴板设置管理本机总允许状态，会话选项只能进一步限制；本机权限/密码放在共享页，
  目标凭据放在连接页。
- 远控时以画面为主，紧凑栏只保留目标、画质、断开/全屏、设置。
  连接期间隐藏凭据编辑；文件进度/取消使用临时提示，不再加常驻工具栏。
  手机/平板用紧凑面板放置等价操作。

连接状态统一为：未连接、搜索中、连接中、已连接、重连中、失败。
共享状态独立为：关闭、启动中、可连接、使用中；修改密码不混用共享/连接状态。
错误说明失败动作及下一步，密码校验在编辑处提示，系统授权使用原生流程。

## 外观与习惯

继续使用已确认的蓝莓色图标：强调色 #5265EC、正文 #202435、次要文字 #697183、
白色内容、内容表面 #F6F7FA、分隔 #E5E8F0；适配可读的系统/深色方案。标题栏不叠加第二个 logo。
Windows 使用 Segoe UI，Mac 使用系统 San Francisco；后续平台使用原生系统字体。

内容层次、间距、左对齐及短标签保持一致，译文有自然伸缩空间。
尊重原生窗口、键盘焦点、辅助功能名称、减少动态效果和触摸目标尺寸；普通控件不加装饰发光。

快捷键随目标系统映射：Windows Ctrl+C/V 对 Mac Command+C/V；反方向提供相应的 Command 到 Control 映射。
保留原生映射选择、退出远控快捷键及失焦/断开释放按键；系统保留组合键、安全桌面仍有平台边界。

## 验收

各原生端检查中英文、最窄桌面宽度、键盘导航/焦点、密码编辑/取消/错误、设备选择不自动授权、
文件提示、全屏及断线恢复。某端截图或模拟检查不能代替另一个系统及手机/平板的实际验收。

## 语言

开发版两端均提供“设置 → 语言 → English / 简体中文”。首次跟随系统语言，主动选择后记忆，
当前界面即时更新，不断开连接。两端复用 `assets/localization/strings.json` 中的同一份词汇。

只翻译控件与应用提示，不翻译密码、设备名、文件路径或剪贴板内容。系统弹窗与底层系统错误详情
保持系统语言。Windows 用带本地化提示及辅助功能名称的紧凑设置/全屏图标，Mac 使用原生菜单；
等价操作可以有符合各系统习惯的呈现方式。

## 设计审阅

[第二轮设计](design.md)已确认，正在逐步接入设置、页面状态和视觉细节。
设置采用通用、连接、剪贴板、关于；共享权限与各自密码由对应任务页面管理。实现时遵守
[实现约定](../../design/review/revision-2.md)。

[产品方向](product.md)和[交互界面方案](design.md)定义下一轮界面迭代；
桌面设计已于 2026-10-10 审阅，正在逐步接入导航和会话布局；
已验证范围与剩余工作见[原生界面进度](native-ui.md)。未来平台界面仍为设计参考。

连接页只呈现设备列表和一个“添加目标”入口。刷新、选择不能自动认证；
用户点击设备后打开连接表单，带入真实地址和设备信息。添加目标打开同一表单供手填 IP。
密码、记住/忘记密码和画质放在表单里，失败保留输入。空列表说明发现或添加方式，不重复按钮。

本机名称或密码尚在编辑时，先保存或取消再开始共享；已有共享仍可停止。
密码保存失败保留原凭据、草稿和会话；保存成功后两端都结束旧共享，等待主动再次开始。
生成/取消不替换密码。停止时清理旧传输提示，启动/停止异步完成前继续占用对应角色。

共享页先呈现本机信息和配对密码，再在本页底部固定区域开始／停止共享。
内容独立滚动，编辑或缩小窗口后停止按钮仍可访问。

共享页在同一内容区域内竖排本机信息和密码；设置按可用宽度和内容高度排列。
切页保留窗口大小。Windows 的软件编码是折叠故障排查里的备用方案，共享期间不能切换；
系统限制放在文档中，不占据常驻兼容面板。

## Windows 字体细化 — 2026-10-12

明确复合字体映射：中文/全角字符使用 Microsoft YaHei UI（不可用时回退雅黑/系统字体），
西文使用 Segoe UI。不能把中文留给 Segoe UI 在 en-US 下隐式回退：原生排版可能在同一个词中
混用微软正黑和日文游 Gothic，还会选择不同的实际字重。Windows 入口标题和用途名称使用
有真实字形支持的 Regular，通过字号和间距建立层次；Mac 保留原生系统字重。

卡片阴影只放在独立背景层，文字不能处于位图特效的子树内。设置齿轮使用已确认矢量几何，
不用 Unicode 符号/emoji。除了布局，还检查实际原生字形、字体和字重。
Windows 界面修订为 `entry-2026-10-12-r2`；Mac 保持前一轮内部构建 24，原生验收仍待完成。
