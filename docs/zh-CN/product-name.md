# 产品命名决定

[English](../product-name.md) · [界面规范](interface.md)

用户于 2026-10-10 确认：

- 正式显示名称：**Local Remote Desktop**。
- 下一次命名迁移的仓库名：**local-remote-desktop**。
- 含义是局域网远程桌面；未来手机、平板控制电脑也符合这一定位。

当前应用和仓库仍叫 LocalRemote，本次记录决定，尚未执行仓库改名。
在 v0.3.0 开发中安排单独迁移，统一应用显示名、文档、安装/构建路径、
产物名称和 AtomGit 链接，并验证现有 Windows 启动路径。

保留已有配对密码、连接记忆、Mac 权限和钥匙串身份，避免因为显示名称改变而重置配置。
旧安装路径提供迁移兼容；已经发布的 tag 和产物保留历史名称，不覆盖。
命名迁移完成并验证后，再把新名称写为已交付状态。文档继续以英文为主，同时维护中文。
