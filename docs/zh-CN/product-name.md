# 产品名称

[English](../product-name.md) · [工程与兼容说明](naming.md)

用户于 2026-10-10 确定正式名称 **Local Remote Desktop**。
AtomGit 仓库已更名为 [local-remote-desktop](https://atomgit.com/zkxw2008/local-remote-desktop)，
仍是原私有仓库，历史提交、tag 和 Release 保留。

名称表达局域网远程桌面，未来手机、平板控制电脑也符合定位。
应用显示名为 Local Remote Desktop；工程、Windows 命名空间/程序集及 Swift 目标/可执行文件
使用 LocalRemoteDesktop。Mac 应用包为 `Local Remote Desktop.app`，Windows 为 `LocalRemoteDesktop.exe`。

保留已有配对密码、连接记忆、接收文件的位置，以及 Mac bundle ID、钥匙串和自启动身份。
发现服务与协议/凭据标记保持兼容。安装仍执行原签名与权限策略；更名不保证临时签名更新可沿用授权。
旧版本发布标题、tag 和产物名称保留，当前开发版本仍为 0.3.0-alpha.1；本次没有发布新 Release。
文档以英文为主，同时维护中文。Mac 控制端及原生验收仍待完成。
