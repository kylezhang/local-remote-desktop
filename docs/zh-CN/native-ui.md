## 当前实现 — 2026-10-12

用户已确认[先选用途设计](entry-design.md)。两端源码已实现“发起连接 / 接受连接”首页，
复用同一套已确认双屏插图。旧常驻侧栏替换为“返回”和右上角唯一带文字的“设置”。
默认外框 600×680 逻辑单位，适配可用屏幕，长内容滚动。

入口只导航。返回保留正在接受的连接和草稿；首页仍有“查看或停止”入口。会话断开回到
连接任务，不清除目标或密码。保留 Mac 证书签名版本原有登录自动启动逻辑：若开始监听，
自动显示接受连接页，确保停止可达。开发签名启动不访问钥匙串。

连接页为单列表和一个添加目标入口，凭据按需弹出。接受连接页竖排名称、本机 IP 和隐藏
密码，底部固定开始/停止接受连接。保留草稿、保存凭据和角色冲突保护。设置仍为四分类，
默认选项、临时会话和本机总允许状态的作用范围保留。

Windows 关于/诊断显示程序集源码标识和 `entry-2026-10-12` 界面修订。
Mac 内部构建号为 **25**；签名包内 `source-revision.txt`、关于/诊断与权限诊断脚本
可核对源码及安装的可执行文件。无 Git 的下载源码标为 unknown，修改中的源码有明确标记。
构建或保留签名检查失败仍保留旧应用；推送源码不等于 Mac 实际更新成功。

## 验证范围

Windows 实际构建和不显示窗口的生产代码检查覆盖中英文紧凑布局、用途导航、首页不读取
共享凭据、监听和草稿保留、手动配对、设置权限边界、反向文字/文件、画质切换、重连及
重复会话清理。采集/输入/剪贴板使用记录型替身，合成 H.264 验证解码像素。
不打开前台窗口，不注入真实输入，不读写用户剪贴板。

Swift 语法和可移植生产 Host/控制端/启动/翻译逻辑以明确平台替身验证。安装、移动目录缓存、
签名及 Mac 打包使用隔离夹具，不代表 Apple 原生服务通过。**Mac 界面和 API 原生编译、
安装后的钥匙串/TCC 仍待验收**；Mac 不在当前开发网络，不尝试 SSH。

这些检查不能证明物理输入被应用接受、真实画面延迟或 Mac 原生视觉一致性。
公开版本仍为 0.3.0-alpha.2，原生双机与升级验收前不创建新 tag/release。
Windows 最终提交打包后再次检查，再复制到空闲的常用启动目录，正在使用的客户端不打断。

## Windows 字体修正 — 2026-10-12

用户实际截图暴露了布局检查漏掉的中文混合字体。原生 WPF 字形复现确认了正黑/游 Gothic
回退及实际字重不一致。现明确中文用 Microsoft YaHei UI，西文用 Segoe UI；入口标题和
角色标签使用 Regular。齿轮改矢量，卡片阴影与文字分层。

原生字形和不显示窗口的 ClientChecks 通过，修订为 `entry-2026-10-12-r2`。
本轮只修 Windows，不改变 Mac 权限、身份或版本。字体/布局检查与实际安装的视觉验收
分别记录，最终包再次检查后才部署。

## 常用页面完整显示 — 2026-10-12

原 560×568 外框的后台原生测量中，普通接受连接页内容高 480、可视高只有 397。
默认改为 600×680，并受可用屏幕限制。中英文首页、常规设备列表、接受连接、四类设置及
添加目标弹窗在默认尺寸下的原生布局检查中没有竖向滚动。共享页收紧部分间距，
目标弹窗的取消/连接固定在滚动字段之外，长错误也不会遮住它们。
小屏幕、长列表、展开编辑与诊断保留滚动；用户自行调整尺寸仍保留。首页内容上下平衡。

Mac 源码同步尺寸和紧凑共享结构，内部构建 25；两端修订为 `entry-2026-10-12-r3`。
Swift 语法、可移植 Host 模型和打包夹具检查通过，Mac SDK/实际界面能否完整显示仍待验收。
交互预览同步尺寸；仓库 PNG 是先前浏览器截图，不作为这一轮原生尺寸验证证据。
