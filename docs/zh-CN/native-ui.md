## 设备名称

“共享此设备 → 本机名称 → 修改名称”编辑并保存本应用的展示名称。“使用系统名称”
只填写草稿，取消保留原值。保存接受 1–32 个 Unicode 字符，移除首尾空白并拒绝控制字符。
改名不停止监听、不更换密码，也不修改操作系统中的电脑名称；Mac 在共享期间重新
发布 Bonjour 名称，Windows 也在共享期间通过系统 DNS-SD 重新发布。

两端共享角色在认证后及原有心跳中返回 `deviceName`。Windows 更新同一地址的列表条目，
刷新时保留当前进程内的已连接记录；这不是持久设备历史，也不代表设备在线。Mac 更新
会话标题及不含密码的最近记录。旧版本字段缺失或无效时保留已有名称或地址。手动改填其他 IP 会清除无关名称和系统。

## 手动配对与密码规则

两端源码用一个弹窗填写目标 IP、密码和记住选项。已知目标显示真实信息；未知目标
在认证后获取名称和系统。取消或认证失败不写入凭据、不创建记录；成功后每次逻辑连接
最多保存一次，存储失败不结束连接。不勾选记住只限制本次保存，不删除以前保存的凭据。
角色切换先验证目标，明确选择后才停止共享。新密码统一 8 位，记录读取和线上校验
继续接受已有长密码。见[配对检查记录](../../tests/results/manual-pairing-2026-10-11.txt)。

## 验证范围

画质、重连和快捷键默认值独立保存，只在一次新连接开始时复制。当前会话的临时调整及
画质重连不会覆盖或重新应用未来默认值。Windows 剪贴板总开关是持久的本机允许状态，
会话开关只能进一步限制；关闭文字共享会立即停止轮询、撤销旧请求并拒绝过期确认，
文件通过原有取消路径停用。新连接重置会话临时限制。Mac 连接默认值也独立保存，
反向剪贴板/文件仍不支持。Mac 本机权限入口属于共享页，不放入连接设置。

Windows 已用 .NET 8 构建。不显示窗口的 WPF 检查覆盖中英文、820/1100/1440 像素布局、
导航、选择设备、取消修改密码、单窗口呈现、会话布局、角色互斥及监听端口清理。
检查使用独立凭据及模拟输入/采集适配器，不代表真实桌面输入、延迟或权限验收。

新增后台检查覆盖四个分类、820/1100 像素布局、100/125/150% 渲染比例、默认值与会话
独立及剪贴板授权撤销。缩放渲染不等于真实显示器 DPI 验收，见
[设置检查记录](../../tests/results/settings-ui-2026-10-11.txt)。

Windows 名称保存、旧字段兜底、独立 DNS-SD 用例和加密连接中的改名传播检查通过。
Swift Foundation 检查使用明确的服务替身，覆盖隔离偏好保存、共享期间改名保留密码与
监听、广播生命周期及控制端名称更新。

Swift 语法及可移植配对/模型检查通过。开发 Mac 已不在当前局域网，SSH 尝试已停止；
