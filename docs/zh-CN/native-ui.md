密码，底部固定开始/停止接受连接。保留草稿、保存凭据和角色冲突保护。设置仍为四分类，
默认选项、临时会话和本机总允许状态的作用范围保留。

## 原生布局与打包修正 — 2026-10-13

新增 [Mac 布局检查](../../tests/MacLayoutChecks/README.md)，以生产界面和模型编译，
不显示窗口地渲染了 18 个中英文用例。默认外框下，首页、空设备列表、接受连接、四类设置
所检查的原生滚动容器均无溢出；目标与密码弹窗以固定测试尺寸渲染。审阅发现并修复了
设置分类控件的重复标签及目标信息提示漏译。新增直接翻译键覆盖检查，共享词库为 347 条。

真实打包发现新版 Bash 测试漏掉了系统 Bash 3.2 的兼容问题：空签名参数数组展开、
变量紧邻中文标点会中断。签名参数改为明确分支，相关输出使用带花括号的变量。
安装器支持普通及带注释前缀的 codesign 输出，仍完整比较与交叉验证签名要求。
临时签名要求改变时，保留权限模式仍在停止/替换旧应用之前中止。

系统 Bash 3.2 下通过 13 个签名用例、4 个缓存用例及 22 个安装测试方法，包含注释前缀、
失败与恢复。隔离目录中的完整生产应用包构建并严格签名验证通过，资源齐全、内部构建 27。
开发临时签名不等于分发签名验收。已安装应用和权限未改动；未激活渲染不能证明激活后的
颜色/焦点、实际弹窗尺寸、钥匙串/TCC 或真实双机输入。见[脱敏记录](../../tests/results/mac-layout-install-2026-10-13.txt)。
