# 开发约定与经验

[English](../development-handbook.md) · [产品目标](product.md) · [界面规范](interface.md) · [版本规划](roadmap.md)

整理于 2026-10-11。新平台开发和既有流程修改前应先阅读；具体实现状态与验证证据以
交付计划和检查记录为准，本文件不代表所有平台已支持。

## 产品目标

- 每个平台一个原生 App，“连接”和“共享此设备”是角色，不是两个产品。
  远控当前已登录桌面；断开后回到原设备，继续同一工作现场。
- 优先解决个人办公室使用的实际需求：连接简单、输入习惯自然、配对可记忆、恢复可预测。
  不引入账号、云中转、公网穿透或无关管理功能。
- 可复用已有 VPN 提供的可达私有 IPv4 路由。手填目标IP不依赖设备发现；
  组播发现未必跨网段，RDP 能连通也不代表本应用端口已开启。
- 桌面继续采用 Swift/C# 原生实现和现有局域网协议，不为输入权限问题贸然重构或改用 WebRTC。
- 各平台分别评估采集屏幕、接收操作、控制其他设备的能力。手机先做控制端不代表永不共享，
  也不承诺任意系统允许完整手机被控；以平台限制和真实证据为准。

## 交互与界面

- 统一术语：目标IP、本机名称、配对密码、连接、共享此设备、开始共享、停止共享。
  跨端保持流程一致，同时使用原生控件、语法和键盘习惯。
- 本机名称默认读取系统，可在共享页修改。被共享 App 通过设备发现与认证后的能力消息
  提供名称和系统类型。未知手填 IP 不凭空展示名称或系统；发现信息不等于身份可信或已授权。
- 新密码统一为恰好 8 位无空格可打印 ASCII 字符，自动生成也为 8 位草稿；旧长密钥兼容。
  编辑、生成和取消不改变当前密码；保存应原子完成，成功后断开旧连接，改用新密码。
- 地址与密码使用系统安全存储记忆。设备列表加载不自动访问钥匙串；
  用户主动连接时才读取所存凭据，失败保留草稿，提供“忘记密码”。
- 设置分为通用、连接、剪贴板、关于。本机共享密码放共享页，目标密码放连接页。
  默认项作用于下一次连接，当前会话的临时调整不回写默认值。
- 全局剪贴板授权是上限，会话选项只能进一步限制。配对后文字和普通文件默认同步，
  曾关闭则保留关闭。已允许会话不增加人工二次认证或逐文件确认。
- 远程画面优先，一条紧凑工具栏，传输使用临时进度/取消提示。
  避免两个 Logo、过宽头部、重复局域网提示和正常使用流程中的实现细节。
- 沿用已认可品牌、配色和原生 Segoe UI/San Francisco。桌面初始外框约 **560×568 逻辑单位**，
  居中并适配可用屏幕、保留边距；首页“发起连接 / 接受连接”双入口，无常驻侧栏，返回保留状态，
  设置统一右上角带文字入口；连接页只保留设备列表和一个添加目标入口，
  点击设备或添加目标后才显示密码和画质表单。共享信息和密码在一个区域中竖排。长内容滚动，
  不把固定宽度表单塞进过宽窗口留下大量空白。支持用户调整/全屏；切页和连接不反复重置窗口。
- 未保存的本机名称/密码草稿阻止开始，保存或取消后恢复；已有共享编辑时仍可停止。
  保存密码成功结束原共享，等待主动再次开始；保存失败保留原会话与草稿。
- 共享遵循先确认信息和密码、再开始的顺序。开始／停止共享放在本页底部固定区域，
  内容独立滚动；编辑展开或缩小窗口后停止操作仍可访问。
- 后续桌面平台遵循内容比例，不机械复制物理像素；手机/平板按可用空间、触控和原生安全区适配。
- 影响流程的设计先评审，再更新原生客户端；已授权的小调整直接实施。
  设计稿中的虚构设备和未来平台须明确，不能当作原生客户端已可用的证据。

## 桌面开发经验

- 设备发现不等于配对。控制使用 TCP 47980，文件内容使用独立 TCP 47981；
  文件通道自动复用配对身份、使用新随机数，并校验当前桌面令牌与授权序号。
  通过能力声明兼容旧端；文件端口失败不应结束桌面共享。
- 快捷键适配目标：Windows Ctrl+C/V 对应 Mac Command+C/V，反向 Command+C/V 对应 Ctrl+C/V。
  焦点丢失、断开和故障释放按键/鼠标；系统提交成功不等于应用实际接受。
- 开启/重连建立新剪贴板基线，收到内容防回环，保留较新的本地复制。
  文字在粘贴按键前发送；文件须接收端确认就绪。提前粘贴抑制整组按键，让用户重试，
  不在稍后自动执行，以免焦点已经改变。
- 当前边界：文字 32 KiB UTF-8；普通文件每批 32 个、单个 4 GiB、合计 8 GiB；
  32 KiB 分块、验证跨平台文件名、提交前核对 SHA-256。
  文件夹、虚拟文件和原始图片像素是后续能力，不混同于普通文件剪贴板。
- 保存路径由接收端生成，不接受对端任意路径；正常取消/失败清理未完成批次，
  已完成文件留给用户管理。改名时保留原接收目录，避免丢文件。
- 明确采集、解码、剪贴板和网络生命周期：有界队列、只保留最新帧、单文件任务、取消和超时。
  剪贴板在界面线程访问；文件、哈希和网络在后台。资源/延迟实测与短功能检查分开记录。
- 不凭感觉宣称死循环。分别排查焦点、授权、输入收到/提交/拒绝计数和传输状态。

## 安装、身份和权限

- 产品名 Local Remote Desktop，仓库 local-remote-desktop，Windows 启动文件/程序集
  LocalRemoteDesktop；旧输出路径仅兼容已有启动位置，不代表重复产品或旧源码目录。
- 保留 com.remotemaclan.host、已有钥匙串/服务标识和凭据，除非经过专门迁移验收。
  外观改名不能悄悄重置权限或丢失配对。
- 先构建；失败保留安装版本。只在授权范围内停止旧实例，然后完整替换旧应用包，
  验证新包、启动文件和图标，不能叠加安装遗留内部文件。
- 正常升级应保留权限；修复/重置是明确说明的路径，不能反复安装、重置、授权作为常规使用。
  重置命令不能直接授权，也不保证删除设置里所有可见项目；系统权限仍需用户确认。
- 临时签名变化可能影响 TCC/钥匙串信任。稳定签名和真实重启/更新验收不可省略；
  不能声称一次源码修改彻底消除密码提示。避免启动时反复读取/写入同一密钥。
- 仅承诺已登录用户会话，不绕过 FileVault 预启动、系统登录/锁屏或 Windows 安全桌面。
  实时采集不是生成录像文件，也不代表支持音频。

## 开发与验证

- 已明确授权的工作持续执行，常规编辑不反复确认。先完成代码和可独立检查，再请用户验收；
  每次回复说明结果、未确定事项和下一步。
- 不在用户工作时弹测试窗口、抢焦点、访问真实剪贴板、采集当前桌面或注入系统输入。
  默认使用不可见布局、生成视频、隔离存储、记录适配器与回环测试；真实交互需约定时段和专用目标。
- 不重试已知不可达的 Mac SSH；只有明确提供可达验证环境后才恢复。
  SSH/CI 是开发工具，不是正常用户使用前提。原生环境缺失时继续 Windows/便携检查。
- 分开记录源码/静态检查、真实平台构建、便携替身、原生运行样例、安装后双机验收和用户反馈。
  明确没运行的部分，不能把 Mock 写成原生成功。
- 原生验收集中成准备好的清单，不让用户反复为编码错误陪测；先自行修好独立失败项。
- Windows 改完重新编译，把已验证包更新到约定启动位置，仅保留一个产品启动文件。
  正在使用时等退出再替换，不强制关闭重开或多启动实例；延后部署只能排队最新已验证候选。

## 仓库与发版

- 英文为主、中文同步，使用共享翻译。README 按背景、介绍、功能、安装、使用、开发、文档、许可组织。
  开头优先介绍产品，开发状态和下载放对应位置，不冗余堆在顶部。
- 使用 AtomGit，不擅自替换托管平台。按明确阶段提交 feat/fix/docs/test/chore，并推送已验证代码。
  构建产物、缓存、本地日志、凭据、证书和个人设备信息不进 Git；忽略规则和已跟踪文件都检查。
- 原创工作采用 GPL-3.0-or-later，保留第三方声明。二进制包包含许可、精确提交的对应源码、
  构建说明、运行库声明与校验值，不混入编译残留。
- 版本范围以[路线图](roadmap.md)与[交付计划](v0.3.0-plan.md)为准：v0.3.0 双向桌面；
  v1.0.0 稳定桌面分发；v1.1.0 Android、v1.2.0 iOS/iPadOS、v1.3.0 Linux、v1.4.0 HarmonyOS
  仍有能力/验收门槛，不是发布日期承诺。Android、iOS/iPadOS 和 HarmonyOS 先做控制端；
  Linux 规划同时支持控制与共享，须明确支持的桌面会话。
- tag 和发行附件保持不可变。版本一致、测试对应提交、干净源码打包并回读发行元数据/附件。
  AtomGit 主页最新发行版选择不等于列表顺序；标题只写 vX.Y.Z（含 alpha/beta 后缀），
  “最新”标记不代表原生验收已完成。
- 双机和原生/安装门槛通过后才发新的稳定桌面版本；仅源码/仅 Windows 的测试版明确未验证部分。

约定变化时，同一提交更新本文件、英文版及对应产品/界面/协议/发版文档。
观察结果放[验证记录](validation.md)，暂定判断保持明确标注。

正常 Mac 安装默认保留权限，签名不兼容在替换前停止；--reset-permissions 是显式修复。设备空状态提供有效下一步，共享/设置区域按内容组织，不用无关功能填空白。

Windows 延后部署不能把“已排队”当作“已更新”。退出后核对目标 DLL 哈希与 SOURCE.txt 是否对应已测试候选。PowerShell 7 启动隐藏 Windows PowerShell 助手时，须从助手自身运行时加载所需模块；继承的模块路径可能导致 Get-FileHash 不可用。记录实际失败信息，并验证相同的隐藏启动路径。

文件任务回调属于发起它的会话与复制批次。本机重新复制（包括用文字替换文件）应取消旧任务、
使旧文件提议失效；发送前校验剪贴板版本，已取消任务不得覆盖新状态。通过隔离记录服务和
端口重用重复检查断开清理；这与长时间资源测量分开记录。

切换画质须取消旧连接的完整尝试（含身份验证），采用最新选择且不覆盖未来连接默认值。
全屏/焦点切换释放远程输入、清理粘贴拦截；仅应用处于前台且选项已收起时恢复画面焦点，
全屏切换忽略按键自动重复。无窗口状态/解码像素检查与真实前台焦点、显示器几何、物理
按键验收分开记录。
