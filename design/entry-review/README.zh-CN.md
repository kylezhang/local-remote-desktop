# 先选用途的入口草图

[English](README.md) · [设计说明](../../docs/zh-CN/entry-design.md)

**2026-10-12 已确认，作为当前原生客户端实现依据。** 首次打开先选“发起连接”或“接受连接”，再进入
对应任务。可离线打开 `index.html`，或在本地服务中预览。应用外的平台、语言、页面
选择按钮只用于评审，实际产品不需要这套导航。

设备、密码全部是虚构示例，刷新后重置。模拟目标密码为 `Blue482X`；复制、刷新、
连接、权限按钮只反馈模拟结果，不联网、不操作剪贴板、不保存凭据或修改系统。
选用途不会开始共享；共享中真正连接其他设备时先确认，取消保留共享。截图来自
浏览器草图，不代表 Mac/Windows 原生运行通过。

后台浏览器检查覆盖中英文 × 两端窗口外观、560 × 568 默认尺寸、窄窗口不横向溢出、
入口、配对错误、密码草稿/取消/保存、待授权和角色切换确认。原生构建和验收范围单独记录于[原生进度](../../docs/zh-CN/native-ui.md)。

当前交互/原生默认尺寸为 600×680；上方 PNG 是此前 560×568 浏览器截图，
不作为本轮原生溢出验证证据。原生测量范围见进度文档。
